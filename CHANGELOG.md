# Changelog

All notable changes to this project are documented here.

## [0.5.0] - 2026-08-18

### Added

- Deterministic multi-threaded C++ Monte Carlo execution with exact serial/parallel comparison.
- Python sensitivity and uncertainty capstone with versioned JSON and dependency-free HTML/SVG.
- One-command reproduction, technical article, demo script, model limitations, and conditional engineering recommendation.
- Detailed LinkedIn Projects, Featured, and Contact info integration guide with IDE/connector boundary warnings.

### Changed

- Promoted the portfolio workflow from production engineering to an auditable Level 5 capstone.

## [0.4.0] - 2026-08-18

### Added

- Cross-platform GitHub Actions for C++, Python, packaging, static analysis, and sanitizers.
- Versioned Python console commands and C++ release installation.
- Randomized invariant and HTML escaping tests.
- Performance regression gate, security review, and incident drill.
- Level 4 operational and release documentation.

### Changed

- Promoted the project from an experiment pipeline to a reproducible release workflow.
- Centralized CMake warning, sanitizer, clang-tidy, and install configuration.

## [0.3.0] - 2026-08-18

- Added versioned JSON, scenario comparison, HTML/SVG reporting, E2E tests, benchmarks, and ADRs.

## [0.2.0] - 2026-08-18

- Added named CLI options, validation, expanded statistics, strict typing, and data contracts.

## [0.1.0] - 2026-08-18

- Initial C++ reliability simulator and Python analytics pipeline.
