# Level 1–5 Portfolio Book

- `LEVEL1-5_PORTFOLIO_GUIDE.md`: 편집 가능한 원고
- `LEVEL1-5_PORTFOLIO_GUIDE.html`: A4 PDF 조판용 HTML/CSS
- `LEVEL1-5_PORTFOLIO_GUIDE.pdf`: 배포·열람용 13페이지 PDF

PDF에는 Level별 목표, CLion/PyCharm 실습, 실행 명령, 통과 기준, 흔한 문제, Level 5 측정 증거, LinkedIn 연결 절차와 최종 체크리스트가 포함되어 있다.

재생성 기준: Markdown을 GitHub Flavored Markdown으로 렌더링한 뒤 Edge headless A4 인쇄를 사용한다. PDF를 갱신할 때 Markdown, HTML, PDF 세 파일을 함께 검토한다.
